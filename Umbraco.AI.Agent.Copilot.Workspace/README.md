# Umbraco.AI.Agent.Copilot.Workspace

Copilot Workspace for Umbraco.AI — a full backoffice section providing a broad-scope, system-wide AI chat with **persisted conversations** and **projects** (grouped conversations + reusable context attachments).

Complements the contextual **Copilot** sidebar (`Umbraco.AI.Agent.Copilot`) under a shared Copilot brand. Ships its durable conversation/project persistence as the reusable `Umbraco.AI.Agent.Conversations.*` sub-packages.

See the [repository README](https://github.com/umbraco/Umbraco.AI) for the full product family.
