# Umbraco AI Copilot Workspace

A full backoffice section for Umbraco.AI: a broad-scope AI chat with persisted, searchable conversation history and projects (grouped conversations plus reusable context attachments — custom instructions, existing AI Contexts, live CMS content, and file uploads).

Copilot Workspace complements the contextual Copilot sidebar, giving editors a durable place for cross-cutting AI work rather than "help me edit this document."
