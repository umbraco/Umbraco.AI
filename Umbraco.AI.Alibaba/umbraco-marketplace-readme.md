## Umbraco.AI.Alibaba

Alibaba Cloud provider for Umbraco.AI - integrate Qwen chat and text embedding models via Alibaba Cloud Model Studio's OpenAI-compatible API.

### Features

- **Qwen Models** - Access current and future Qwen chat models
- **Text Embeddings** - Access Alibaba Cloud's text embedding models
- **Chat Completions** - Streaming and non-streaming chat with tool calls
- **Dynamic Model Discovery** - Automatically fetches available models from Model Studio
- **Custom Endpoints** - Support for the China (Beijing) region or workspace-scoped endpoints

### Requirements

- Umbraco CMS 17.0.0+
- Umbraco.AI 17.0.0+
- .NET 10.0
- Alibaba Cloud Model Studio API key
