## Umbraco.AI.DeepSeek

DeepSeek provider for Umbraco.AI - integrate DeepSeek's chat models via their OpenAI-compatible API.

### Features

- **DeepSeek Models** - Access all current and future DeepSeek chat models
- **Chat Completions** - Streaming and non-streaming chat with tool calls
- **Dynamic Model Discovery** - Automatically fetches available models from the DeepSeek API
- **Custom Endpoints** - Support for proxy servers or alternative endpoints

### Requirements

- Umbraco CMS 17.0.0+
- Umbraco.AI 1.0.0+
- .NET 10.0
- DeepSeek API key
