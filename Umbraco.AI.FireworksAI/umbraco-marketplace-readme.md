## Umbraco.AI.FireworksAI

Fireworks AI provider for Umbraco.AI — fast open-source model inference via Fireworks' OpenAI-compatible API.

### Features

- **Open-Source Models** — Access Llama, Qwen, DeepSeek, Mistral, and more through one provider
- **Chat Completions** — Streaming and non-streaming chat with all serverless chat models
- **Text Embeddings** — Vector embeddings for retrieval and semantic search
- **Dynamic Model Discovery** — Automatically fetches available models from the Fireworks catalog with correct capability classification
- **Custom Account Support** — Point at your own Fireworks account to use fine-tuned or private models

### Requirements

- Umbraco CMS 17.0.0+
- Umbraco.AI 1.0.0+
- .NET 10.0
- Fireworks AI API key
