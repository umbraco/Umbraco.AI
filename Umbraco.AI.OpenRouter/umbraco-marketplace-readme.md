## Umbraco.AI.OpenRouter

OpenRouter provider for Umbraco.AI — one connection to hundreds of chat models from dozens of vendors through OpenRouter's OpenAI-compatible API.

### Features

- **Broad Model Catalog** — Access OpenAI, Anthropic, Google, Meta, Mistral, DeepSeek, and more through one provider
- **Chat Completions** — Streaming and non-streaming chat with any OpenRouter chat model
- **Dynamic Model Discovery** — Automatically fetches available models from the OpenRouter catalog
- **Per-Model Sampling Support** — Hides sampling settings a selected model doesn't accept, based on OpenRouter's own per-model capability data

### Requirements

- Umbraco CMS 17.0.0+
- Umbraco.AI 1.0.0+
- .NET 10.0
- OpenRouter API key
