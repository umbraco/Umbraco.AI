## Umbraco.AI.ZAI

Z.AI provider for Umbraco.AI - integrate Z.AI's GLM chat models via their OpenAI-compatible API.

### Features

- **GLM Models** - Access all current and future Z.AI GLM chat models
- **Chat Completions** - Streaming and non-streaming chat with tool calls
- **Dynamic Model Discovery** - Automatically fetches available models from the Z.AI API
- **Custom Endpoints** - Support for proxy servers or alternative endpoints

### Requirements

- Umbraco CMS 17.0.0+
- Umbraco.AI 17.0.0+
- .NET 10.0
- Z.AI API key
