AI Disclosure Notice
Shows a notice on chat and prompt responses saying they are AI-generated. You may be legally required to tell people when content is AI-generated, for example under the EU AI Act. Check which rules apply to you before choosing Dismissible or Off.
Personal Context
Let users add their own AI Contexts and resources in their profile, for prompts and agents that include personal context. Turning this off stops every prompt and agent using them. Saved contexts and resources are kept.
Agent Memory
Let agents that have memory turned on remember facts between chats. Turning this off stops every agent using memory. Saved memories are kept.
Personal Memory
Whether agents may remember things about each person, like their preferences and role. Only agents set to "Work and person" use it. Turning it off keeps saved memories, paused.
