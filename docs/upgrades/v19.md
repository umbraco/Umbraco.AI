# Upgrade to Umbraco 19

From `18.x` (floor `18.0.0`, compared against `release-18.3.1`) to `19.0.0-beta1` (tag
`release-19.0.0-beta1`). Branch `v19/topic/cms-19-upgrade`, cut from `v19/dev` (itself cut from
`v18/dev` at `6ec12f10f` on 05-11-2026).

**Targets CMS release:** `19.0.0-rc1` (refreshed 12-11-2026, see "Refresh to 19.0.0-rc1").
The rc1 GitHub release is still a draft and the tag isn't pushed; it targets `release/19.0`, read
at `b158b784ce0`. Was `release-19.0.0-beta1`. While this is a pre-release, every product's own
version is a pre-release too (`19.0.0-rc.1`, dotted, per CLAUDE.md). No `19.0.0-beta.1` was ever
published (no `Umbraco.AI@19*` tags).

**Scope:** 26 products. Umbraco.AI.Deploy, Umbraco.AI.Prompt.Deploy and Umbraco.AI.Agent.Deploy
joined on 11-11-2026, on Umbraco.Deploy `19.0.0-beta1` (see "Umbraco Deploy 19"). Umbraco.AI.Automate
stays on 18 for now (see Blockers).

  `AISerializedEntity.Data`).
- Removed: the 13 members marked "Will be removed in v3". Use the builder overload that replaces
  each one; its first argument is an `Action<Builder> configure` (`.WithAlias(...)`, optional
  `.WithProfile(...)`, `.WithChatOptions` / `.WithEmbeddingOptions` / `.WithSpeechToTextOptions`).
  `WithAlias` is required (the builder throws without it). The old methods logged under a fixed
  alias (`"chat"`, `"embedding"`, `"speech-to-text"`); pass the same alias to keep log and audit
  names unchanged:
  - `IAIChatService`: `GetChatResponseAsync(messages, options)` and

    `GetChatClientAsync(profileId)` → `CreateChatClientAsync(configure)`.

    `GenerateEmbeddingAsync(configure, value)`; `GenerateEmbeddingsAsync` (2 overloads) →
    `GenerateEmbeddingsAsync(configure, values)`; `GetEmbeddingGeneratorAsync(profileId)` →
    `CreateEmbeddingGeneratorAsync(configure)`.

    `TranscribeAsync(profileId, audioStream, options)` → `TranscribeAsync(configure, audioStream)`;
    `GetSpeechToTextClientAsync(profileId)` → `CreateSpeechToTextClientAsync(configure)`.
